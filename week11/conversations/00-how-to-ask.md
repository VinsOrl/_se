# How to ask (question templates)

- **Explain:** "Explain `<concept>` like I know Python but not LLM APIs. One small example."
- **Why:** "Why does `<code/rule>` work this way? What breaks if I don't do it?"
- **Compare:** "What's the difference between `<A>` and `<B>`? When do I pick each?"
- **Check me:** "Here is my understanding: `<my words>`. What is wrong or missing?"
- **Debug:** "I ran `<command>`, expected `<X>`, got `<Y + error>`. What's the likely cause?"
- **Minimal:** "What is the smallest code that shows `<idea>`? No frameworks."
- **Next:** "I understand `<X>`. What one thing should I learn next, and why?"

Rule: one question at a time; paste real code/output; end with what I'll try.
